┌──────────────────────────────────────────────────────────────────────────────┐
│  🚀 DÉMARRAGE RAPIDE (5 MINUTES)                                             │
└──────────────────────────────────────────────────────────────────────────────┘

ÉTAPE 1 - Vérifier les prérequis
  $ java -version       # Java 17 ou 21
  $ mvn -version        # Maven 3.8+
  $ mysql --version     # MySQL 8.0+

ÉTAPE 2 - Créer la base de données
  $ mysql -u root -p
  mysql> CREATE DATABASE construction_material_db CHARACTER SET utf8mb4;
  mysql> EXIT;

ÉTAPE 3 - Importer les données de test
  $ cd construction-material-management
  $ mysql -u root -p construction_material_db < database/init_database.sql

ÉTAPE 4 - Configurer le backend
  Éditer: backend/src/main/resources/application.properties
  Modifier:
    - spring.datasource.password=VOTRE_MOT_DE_PASSE_MYSQL
    - jwt.secret=VotreCléSecrète...

ÉTAPE 5 - Compiler et lancer
  $ cd backend
  $ mvn clean install -DskipTests
  $ mvn spring-boot:run

ÉTAPE 6 - Vérifier
  Ouvrir: http://localhost:8080/swagger-ui.html
  Tester le login avec: admin / password123

└──────────────────────────────────────────────────────────────────────────────┘

Authentification:
  POST   /api/auth/login           - Connexion utilisateur
  POST   /api/auth/register        - Inscription utilisateur

Projets:
  GET    /api/projects             - Liste des projets
  POST   /api/projects             - Créer un projet
  GET    /api/projects/{id}        - Détails d'un projet
  PUT    /api/projects/{id}        - Modifier un projet
  DELETE /api/projects/{id}        - Supprimer un projet

Documentation Interactive:
  http://localhost:8080/swagger-ui.html

┌──────────────────────────────────────────────────────────────────────────────┐
│  ⚠️  IMPORTANT                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

1. Le script SQL database/init_database.sql doit être créé avec toutes
   les données de démonstration. Un modèle complet est fourni dans la
   documentation.

2. Avant de lancer le serveur, assurez-vous que:
   - MySQL est démarré
   - Le port 8080 est libre
   - Les identifiants MySQL dans application.properties sont corrects

3. Pour changer la langue de l'API, utilisez:
   - Header: Accept-Language: en
   - Paramètre: ?lang=pt
